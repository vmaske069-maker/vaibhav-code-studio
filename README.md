# Vaibhav Code Studio

A small installable web app for practicing C, C++, Python, Java and JavaScript.

## Run locally
Open `index.html` in a modern browser. The editor works locally, but running code requires internet and a hosted secure origin.

## Install on Android
1. Upload this folder to a static host that provides HTTPS (for example, GitHub Pages or Netlify).
2. Open the hosted website in Chrome on Android.
3. Open Chrome's menu (⋮) and choose **Add to Home screen** or **Install app**.
4. Launch **Vaibhav Code Studio** from the new home-screen icon.

## Notes
- Program execution is sent to the Piston online execution service.
- Do not submit passwords, API keys, private data, or sensitive information.
- This is a lightweight learning editor, not a full VS Code replacement.
